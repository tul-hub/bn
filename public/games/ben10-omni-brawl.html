MultiplayerLocal multiplayer on the main menu: one player creates a room, the other joins with the code (same network and server as ludo.html).
TouchLeft joystick moves (up = jump, down = block). Right buttons attack. Tap any alien icon, or the green Omnitrix button, to transform instantly.

Transforming has no limit, so swap forms in the middle of a combo. The one exception is Alien X, which needs a 3 second charge first. Win two rounds, then press SPECIAL when FINISH HIM! appears.
